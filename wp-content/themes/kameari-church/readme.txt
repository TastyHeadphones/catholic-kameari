A calm, editorial WordPress theme for Catholic parishes. Bone-and-ink surfaces,
a single sumi-green accent, Mincho display type, and a Japanese-first rhythm.

== Description ==

Kameari Church is a standalone classic theme — it needs no parent theme and no
page-builder plugin. The front page is assembled from parish content you enter
in wp-admin: Mass times, a liturgical calendar, parish activities, clergy, and
your ordinary posts as news.

Twelve inline SVG illustrations (rosary, candles, chalice, stained glass, a
stylised neighbourhood map, and more) stand in wherever a photograph is missing,
so the site never shows a broken image on day one.

== Frequently Asked Questions ==

= Where do the Mass times come from? =

Mass Times → Add Mass Time in wp-admin. Each row has a day, a time, a note, and
a "highlight this row" switch for the principal Sunday Mass.

= How do I change the address in the footer and the access strip? =

Appearance → Customize → Contact & access.

= Can I turn the Google Fonts request off? =

Yes. Appearance → Customize → Church identity → "Load fonts from Google Fonts".
The theme then falls back to Hiragino Mincho / Yu Mincho and the system sans,
which are present on most Japanese devices.
